## 배운 것
- **PowerShell**: 명령어를 입력하는 창
- **winget**: 프로그램 설치 도구
- **마크다운**: 기호로 서식을 표시하는 글쓰기 규칙
- **Git**: 파일의 변경 이력을 기록하는 도구
- **GitHub**: Git의 기록을 인터넷에 보관하고 공유하는 곳
- **HTML**: 웹페이지의 뼈대를 만드는 태그
- **CSS**: 색 크기 배치를 꾸미는 규칙 (style.css)
- **개발자 도구**: 브라우저에서 코드를 확인하고 미리 고쳐 보는 도구
- **GitHub Pages**: 저장소를 인터넷 주소로 무료 배포하는 기능
